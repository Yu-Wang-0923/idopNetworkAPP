# idopNetwork App

Streamlit-based web application for the idopNetwork complex systems analysis platform.

## Installation

```bash
pip install idopnetwork-app
```

## Usage

```bash
idopnetwork-app
```

## Multilayer network overview

After running a multilayer reconstruction in NetRecon, open **Multilayer network overview**. Select conditions and modules, draw the overview, and download the combined figure as SVG.
